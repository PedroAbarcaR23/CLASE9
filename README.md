# Clase 9 · PLC y programación en escalera

Abra index.html en un navegador. HTML, CSS y JavaScript funcionan localmente y sin conexión; solo los enlaces de documentación requieren Internet.

La presentación tiene 49 diapositivas: fundamentos e historia, hardware y señales, ejecución y scan, lógica booleana, Ladder, marcha-paro, temporizadores, contadores, aplicaciones, ejercicios y seguridad.

Controles: flechas izquierda/derecha, Inicio/Fin; índice para saltar a cualquier diapositiva; guía docente con preguntas y explicaciones por filmina; pantalla completa. Los ejercicios incluyen soluciones desplegables. El botón de pausa congela el temporizador didáctico, no bloquea los controles manuales.

Prácticas interactivas: tabla AND/OR/NOT, scan manual, marcha-paro, TON de 3 segundos, CTU por flanco y comprobación de conceptos. El temporizador se reinicia al abandonar su diapositiva y no avanza en segundo plano.

Duración sugerida: 90–120 minutos, ajustable. Para 60 minutos, priorice fundamentos, scan, contactos y marcha-paro. Proyecte en pantalla completa para mejor legibilidad.

Alcance: modelos educativos, no un proyecto ejecutable para un PLC concreto ni diseño de seguridad de maquinaria. Consultar manuales del equipo para instrucciones, E/S, ejecución y comportamiento reales. No conectar cargas ni modificar máquinas basándose en estos ejemplos.

Verificación del modelo lógico: node test-model.js. La impresión del navegador imprime solo la filmina visible.

GitHub Pages: conservar todos los archivos de esta carpeta y abrir Clase%209/index.html desde la raíz publicada. No se incluyen dependencias, CDN ni rutas absolutas en la presentación.
